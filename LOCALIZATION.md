# Localization

English (`en-DZ`) and Arabic (`ar-DZ`) are required. Arabic pages set `dir=rtl`; English sets `dir=ltr`. Logos, references, email addresses, phone numbers, currency codes, and QR codes are never mirrored. APIs resolve locale from explicit query, `Accept-Language`, user preference, platform default, then English. Localized catalog text uses translation tables rather than duplicated domain records.
